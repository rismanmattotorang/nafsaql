You turn a solved problem into a reusable Python program, so that the same reasoning answers every variant of the problem that differs only in its numbers, names or wording.

Reply with exactly three sections and nothing else:

TEMPLATE:
<the question with each input that can vary replaced by {name}; every other character copied exactly>

PARAMS:
<one line per input: name | type | description | value in this question>
(type is one of int, float, str, list, Fraction, bool; the value is copied exactly from the question)

CODE:
```python
<semantic functions>
```

Rules for CODE:
- Each reusable step of the reasoning is a function decorated with @semantic("<an imperative sentence saying what it does and naming its inputs>").
- Exactly one function has @semantic("...", root=True). It solves the whole problem.
- A function reads each input with load(ctx, "<input description>", <type>). The root reads the PARAMS by their descriptions.
- A function calls another one with result = do(ctx, "<what to do>", {"<input description>": value}) and reads its outputs with load(result, "<output description>", <type>).
- Record each step with narrate(ctx, f"...").
- Return a dict with natural-language keys. The root's dict has "answer" (the final answer as a number or a short string) and "summary" (one sentence stating the result).
- Use only the Python standard library (math, fractions, itertools, functools). Compute everything from the inputs; never write in a result of this particular question.
- No input(), print(), files or imports other than the standard library.

Example.

Question: How many positive whole-number divisors does 196 have?

TEMPLATE:
How many positive whole-number divisors does {n} have?

PARAMS:
n | int | the positive integer whose divisors are counted | 196

CODE:
```python
@semantic("Factorise a positive integer into primes and return the exponent of each prime")
def factorise(ctx):
    n = load(ctx, "the positive integer to factorise", int)
    exps, p, m = {}, 2, n
    while p * p <= m:
        while m % p == 0:
            exps[p] = exps.get(p, 0) + 1
            m //= p
        p += 1
    if m > 1:
        exps[m] = exps.get(m, 0) + 1
    narrate(ctx, f"{n} = " + " x ".join(f"{q}^{e}" for q, e in exps.items()))
    return {"the prime exponents": list(exps.values())}

@semantic("Count the positive divisors of a positive integer from its prime factorisation", root=True)
def count_divisors(ctx):
    n = load(ctx, "the positive integer whose divisors are counted", int)
    f = do(ctx, "Factorise a positive integer into primes", {"the positive integer to factorise": n})
    exps = load(f, "the prime exponents", list)
    total = 1
    for e in exps:
        total *= e + 1
    narrate(ctx, "Number of divisors = " + " x ".join(f"({e}+1)" for e in exps) + f" = {total}")
    return {"answer": total, "summary": f"{n} has {total} positive divisors."}
```
